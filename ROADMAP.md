# proev.ru — Roadmap

## v0.1 ✅ Выпущено
- Карта зарядных станций (OSM/Яндекс/2GIS, OCM + OSM данные)
- Лента новостей (RSS, автоодобрение, фильтры, поиск, фото)
- Каталог сервисов с категориями
- Мини-лендинги партнёров (/services/[slug])
- Регистрация партнёров + одобрение через AdminJS
- Личный кабинет партнёра (7 разделов)
- Мобильная адаптация всех страниц
- Демо-партнёр для презентаций

---

## v0.2 — Безопасность (приоритет: высокий)

- [ ] JWT-токены вместо base64(userId) для партнёрского API
- [ ] Форма смены пароля в AdminJS без передачи пароля в URL
- [ ] 2FA для администраторов (TOTP через Google Authenticator / Telegram OTP)
- [ ] 2FA опционально для партнёров
- [ ] Rate limiting на /api/partners/login и /api/partners/apply
- [ ] HTTPS-only cookies для сессий AdminJS
- [ ] Аудит-лог действий администраторов (кто одобрил/отклонил заявку)

## v0.3 — Карта и данные

- [ ] Overpass API (OSM) — исправить 406, загрузить тысячи российских станций
- [ ] Яндекс Карты Геопоиск API — импорт станций из базы Яндекса (включает данные Яндекс Заправок)
- [ ] Electro.cars OCPI — реальные статусы зарядных сессий от операторов
- [ ] Возможность водителю обновить статус станции прямо с карты
- [ ] Кластеризация по городам на низких зумах
- [ ] Маршрут между зарядками (A → B с остановками)

**Примечание по Яндекс Заправкам:** прямого публичного API нет. Данные доступны через Яндекс Карты Геопоиск API (платно, ~₽3000/мес) — запрос `"зарядная станция"` возвращает все ЭЗС из базы Яндекса включая партнёрские сети.
