## 🔴 СРОЧНО — критичные баги и дыры (делаем прямо сейчас)

### 1. Авторизация партнёра — JWT (1-2 дня)
**Проблема:** токен — это просто `base64(userId)`, подделывается за 2 секунды
**Решение:** заменить на подписанный JWT с expiry и refresh token
```
- POST /api/partners/login → { accessToken, refreshToken }
- GET  /api/partners/me с Bearer токеном
- POST /api/partners/refresh
- Удалить localStorage, перейти на httpOnly cookie
```

### 2. Rate limiting (1 день)
**Проблема:** `/api/partners/login` — открыт для брутфорса
**Решение:** `@nestjs/throttler` — 5 попыток / 15 минут на IP

### 3. Email партнёру при одобрении заявки (2 часа)
**Проблема:** временный пароль показывается только в AdminJS, если закрыть — всё, пароль потерян
**Решение:** при одобрении заявки отправлять email с паролем и ссылкой на кабинет

### 4. Форма смены пароля в кабинете (4 часа)
**Проблема:** сейчас нет UI для смены пароля самим партнёром (только через сброс по email)
**Решение:** раздел «Настройки» → вкладка «Безопасность» → форма (текущий + новый + подтверждение)

## 🟡 v0.2 — Рост данных и карта (приоритет: высокий)

### Карта — главная ценность платформы

**OSM Overpass API — исправить 504**
- Сейчас падает с 504 при старте
- Решение: перенести в отдельный cron каждые 24 часа, добавить retry с exponential backoff
- Цель: 1000+ станций в РФ из OSM

**OCPI Electro.cars** _(ждём ответа от партнёра)_
- Готов handshake эндпоинт и синхронизация
- Как только дадут доступ — тест синхронизации за 30 минут
- Даст реальные статусы от зарядных сетей

**Обновление статуса от водителей**
- Кнопка «Обновить статус» на карточке станции
- Форма: работает / занята / неисправна + комментарий
- Агрегация: если 3+ подтверждений за 2 часа — обновляем статус

**Кластеризация на карте**
- `supercluster` или встроенные кластеры MapLibre
- На зуме < 8 показываем кластеры с числом станций
- Клик по кластеру → зум

**Яндекс Карты Геопоиск** _(платно, ~₽3000/мес)_
- Запрос «зарядная станция электромобиль» → +200-300 станций из базы Яндекса
- Добавить как Integration в AdminJS
